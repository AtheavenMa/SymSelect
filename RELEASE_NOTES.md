# SymSelect v0.1.0 — reference and offline demo release

Included: reusable top-k cosine alignment PyTorch API, offline arithmetic selection demo, exact autograd theory counterexample, bilingual README and CPU tests.

This release is deliberately **not** a full MNS/I-RAVEN reproduction: current manuscript values are **paper-reported**, while the educational demo uses synthetic arithmetic expressions.

For the original complete ZIP assembled with the current paper figures and extended documentation, see the ChatGPT-provided release archive supplied to the project owner. No third-party benchmark checkpoint or training source was provided in that archive.
