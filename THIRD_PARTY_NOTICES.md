# Third-party materials and asset provenance

The SymSelect reference method and arithmetic demo are original implementation code distributed under MIT.

No original MNS or I-RAVEN datasets, pretrained checkpoints, third-party benchmark training code, or earlier experiment outputs are included in this GitHub code transfer. Do not confuse synthetic arithmetic demo metrics with benchmark results.

The companion locally assembled ZIP contains visual assets rasterized from the project owner's supplied current manuscript. Rights to scientific figures and benchmark source assets should be verified before further redistribution.

PyTorch and Matplotlib are optional or mandatory runtime dependencies subject to their respective licenses.
